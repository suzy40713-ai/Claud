# Booky, la mascotte BookSync

Un petit calendrier bleu (couleurs et coche du logo BookSync), dessiné en SVG : libre d'utilisation pour BookSync.

- `booky.svg` : fichier source (modifiable, animable : groupes `arm-l`, `arm-r`, `eyes`, `mouth`)
- `booky.png` : Booky sur fond transparent (800 × 880)
- `booky-photo-profil.png` : photo de profil TikTok / Instagram (800 × 800, fond bleu)

Couleurs : bleu #3563E9, bleu foncé #1E3FA8, blanc, joues #FF8FA3.
